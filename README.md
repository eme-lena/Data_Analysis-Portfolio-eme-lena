## Проект 1: Анализ рекламных кампаний (Iconique)
**Бизнес-задача:** Сравнение эффективности рекламных каналов Google Ads и Яндекс.Директ за 2019–2021 гг. для оптимизации медиаплана и повышения возврата инвестиций (ROMI).

### Ключевые метрики
- **CPO** (Cost Per Order) – стоимость привлечения заказа
- **ROMI** – возврат маркетинговых инвестиций
- **ACOS / Соотношение расходов к доходу** – эффективность затрат
- **Средний чек & Конверсия** – качество трафика по типам кампаний

### Структура дашборда
- Сравнение платформ по годам и типам РК (бренд, категория+бренд, смарт-баннеры ретаргетинг, конкуренты, релевантная тематика)
- Динамика заказов, расходов и доходов
- Детализация по гео (Москва / РФ) и аудиториям (М/Ж, 21+)
- Топ-кампании с разбивкой по CPO и ROMI

### Инструменты
`Power BI Desktop (.pbiх)` | `DAX` | `Excel` | `Git`

### Как открыть
1. Скачайте файл `Iconique_Analysis.pbix` из папки `03_powerbi/`
2. Откройте в Power BI Desktop 
3. При необходимости укажите путь к обезличенному датасету в `02_data/`

## Инженерный стек & ETL-архитектура
Помимо BI-визуализации, обладаю практическим опытом построения end-to-end пайплайнов данных:

| Компонент | Описание |
|---|---|
| **Orchestration** | Apache NiFi: настройка потоков, обработка ошибок, логирование, back-pressure |
| **Источники** | Открытые реестры (ФНС, адресный справочник), парсинг/дамп веб-сайтов, API |
| **Архитектура ХД** | DataVault 2.0: Raw Vault (Hub, Link, Sat), Business Vault, информационные витрины |
| **Загрузка** | Инкрементальная обработка, SCD Type 2, валидация схем, идемпотентность |

> *Понимание DataVault 2.0 и NiFi позволяет проектировать BI-решения с учетом масштабируемости, аудита изменений и качества данных на этапе ingestion.*
